
# 🐟 Pedidos da Cantina - Grupo 04 (Tambaqui)

Sistema para gerenciamento de pedidos de uma cantina, desenvolvido como atividade acadêmica.

## Sobre o projeto

A aplicação permite registrar pedidos de produtos do cardápio, controlar suas situações e consultar os valores dos pedidos.

Cada pedido contém apenas um item do cardápio, podendo possuir várias unidades.

## Funcionalidades

- [ ] Listar itens do cardápio.
- [ ] Registrar pedidos.
- [ ] Informar a quantidade de unidades.
- [ ] Calcular o valor total do pedido.
- [ ] Listar pedidos cadastrados.
- [ ] Filtrar pedidos por situação.
- [ ] Atualizar situação dos pedidos.
- [ ] Alterar preço dos itens do cardápio.

## Regras de negócio

- A quantidade deve ser maior que zero.
- O preço dos produtos é armazenado em centavos.
- O total é calculado pela quantidade multiplicada pelo preço unitário.
- O pedido mantém o preço registrado no momento da criação.
- Alterações no cardápio afetam somente novos pedidos.
